# Fretboard Notebook (吉他課筆記)

An interactive study companion for my guitar lessons: scales, the 5 positions, 型 cells, major/minor (A/B counting), modes, and practice quizzes. EN / 中文 switch in the top-right.

Open `index.html` in a browser. No build step and no dependencies. Settings are remembered in the browser.

- `js/theory.js`: scales, spelling, labels, and the P1–P5 position builder (reproduces the lesson charts)
- `js/fretboard.js`: SVG fretboard renderer
- `js/audio.js`: plucked-string synth (Web Audio)
- `js/content.js`: bilingual explanations and lesson-note transcriptions
- `notes/`: photos of the original lesson pages

URL shortcuts: `index.html?tab=cells&lang=zh&tonic=9&mode=5&pos=2`
